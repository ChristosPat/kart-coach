# Kart Coach

Εφαρμογή Android για καρτ: χαρτογράφηση πίστας με GPS, γραμμές αφετηρίας/sectors, χρονομέτρηση γύρων και ιστορικό.

## Εγκατάσταση στο κινητό

1. Στο κινητό άνοιξε: https://github.com/ChristosPat/kart-coach/releases/latest
2. Πάτα το αρχείο **KartCoach-….apk** για να κατέβει.
3. Άνοιξε το αρχείο. Αν ρωτήσει, επέτρεψε «εγκατάσταση από άγνωστες πηγές» για τον browser.
4. Πάτα **Εγκατάσταση**.
5. Την πρώτη φορά η εφαρμογή θα ζητήσει άδεια **Τοποθεσίας** → «Κατά τη χρήση της εφαρμογής».

Κάθε νέα έκδοση χτίζεται αυτόματα από το GitHub (καρτέλα **Actions**) και εμφανίζεται στα **Releases**.
Η νέα έκδοση εγκαθίσταται πάνω στην παλιά και κρατά τις πίστες και τους χρόνους σου.

## Οργάνωση κώδικα

- `App.js` — η στοίβα οθονών και ο προσανατολισμός (όρθια / οριζόντια)
- `src/core/` — η «μηχανή»: γεωμετρία, χαρτογράφηση, γραμμές, χρονομέτρηση (με τεστ στο `tests/`)
- `src/screens/` — οι οθόνες
- `src/storage.js` — αποθήκευση μέσα στο κινητό
- Σχέδιο: έγγραφο `sxedio-efarmogis` στο Claude Project «Kart Coach»
